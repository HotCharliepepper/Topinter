# TOP INTERIOR DOBONG × WEPLACE · Proposal R2 / 미팅 인계

작업일: 2026-11-02 · 상태: 구현 및 로컬 브라우저 기능 검수 완료 / 가격·사업자·작업 범위 고객 승인 전

## 1. 미팅에서 바로 쓰기

- `index.html`을 Chrome/Edge로 열고, 이전/다음 버튼 또는 방향키(← →)로 이동합니다.
- 10번째 화면에서 세 가지 기본 상품 중 하나를 클릭하면 오른쪽 **선택 견적 구성** 메뉴가 열립니다.
- GBP 세팅 / 홈페이지 개발 / 호스팅·배포 중 필요한 항목을 직접 선택합니다. **어떤 추가 메뉴도 자동 선택하지 않습니다.**
- 선택한 추가 메뉴의 금액은 최초 미정입니다. 해당 항목의 금액을 **만원 단위, 공급가(VAT 별도)**로 입력하면 견적 합계가 갱신됩니다.
- 추가 메뉴 가격을 입력하지 않으면 **최종 합계는 미정**이라고 표시합니다. 미정 금액을 0원으로 처리하지 않습니다.
- 견적 서랍의 **현재 구성 복사**, 마지막 화면의 **미팅 기록 JSON 저장 / 1장 요약 인쇄**를 활용할 수 있습니다.
- 실제 시공 사진은 상단 `미팅 도구`에서 사용권 확인 후 JPG/PNG/WebP를 불러와 시안에만 임시 반영할 수 있습니다. 서버 전송·저장되지 않습니다.

## 2. 기본 3안 (전부 제안 가안, VAT 별도)

| 구분 | 금액 | 제공 방식 |
| --- | ---: | --- |
| A. 월간 성장 운영 | 월 300,000원 × 12개월 = 3,600,000원 | 월 1건 시공 콘텐츠 가안 및 월간 점검 (사진 자료 공급 전제) |
| B. 연간 기본 관리 | 1년 일괄 1,800,000원 | 분기별 정보·사진·FAQ 정비 및 분기 점검 가안 |
| C. 1회성 초기 정비 | 1회 1,800,000원 | 시공 2건 콘텐츠 원고와 사업정보·상담 안내 원고 1회 납품 가안 |

기본 상품에 신규 홈페이지 코딩, Google 비즈니스 프로필 신규 세팅, 호스팅을 자동 포함하지 않습니다. 추가 메뉴를 선택해 별도로 협의합니다. 세 상품은 제공 기간과 작업량이 다른 별도 상품으로, 일괄결제를 통한 동일 상품의 할인 비교가 아닙니다.

## 3. 추가 선택 3안 · 단가 미확정

- Google Business Profile 세팅: 무료 Google 플랫폼의 별도 유료 **설정 대행** 서비스. 기존 프로필·소유권·자격·인증 지원 및 정보 정비.
- 홈페이지 개발: 실제 시공 사진을 활용하는 모바일 사이트, 공종/사례/FAQ/문의 구조. 개발 규모·인도·수정 횟수 계약 확인.
- 호스팅/배포 관리: SSL·도메인 연결·기본 배포 및 유지 점검의 1년 단위 제안 가안. 도메인·외부 서비스 실비 및 갱신 비용 별도 확인.

부가세 시뮬레이션은 공급가의 10%를 가산합니다. 실제 과세/청구·납기·환불·유료 외부 실비는 계약 시 별도 확인합니다.

## 4. 상태와 주의사항

- **확인 필요:** 탑인테리어 도봉의 공식 사업자·대표자·공종·주소/서비스 지역·채널 소유권·실사진·견적/AS·해지/환불·추가 메뉴 단가.
- 과거 동명 '탑인테리어' 거래처와 동일 사업자로 취급하지 않습니다.
- GBP 등록은 업체 자격과 소유권·플랫폼의 인증 절차를 따라야 하며 인증 성공·노출 순위는 보장되지 않습니다.
- Google Business Profile 자체는 무료입니다. 추가 견적은 대행 수수료입니다. 공식 도움말: https://support.google.com/business/answer/2911778?hl=ko
- 모든 수치, 선택 결과는 **제안과 계산 예시**이지 실제 결제 승인, 계약 체결, 매출 성과가 아닙니다.
- 제안서에는 `noindex,nofollow`가 설정되어 있으나, 미팅 정보가 포함된 파일이므로 **일반 공개 배포 전 검토**가 필요합니다.

## 5. 검수 내역

- 1440×900 데스크톱, 390×844 모바일, Chromium 헤드리스 HTML 실행 확인. 동적 JS 실행 오류: 0건.
- 기본 A 공급가 360만원 → VAT 포함 396만원, 기본 B/C 공급가 180만원 → 각 VAT 포함 198만원을 구현.
- A + 홈페이지 공급가 150만원 + GBP 공급가 40만원을 수동 입력하면 예상 공급가 550만원, VAT 포함 605만원, 가정한 최초 납부액 242만원으로 계산됨. **입력한 150/40만원은 QA 테스트값이며 고객 제안가가 아님.**
- 추가 가격 공란 시 전체 총액을 보류하고, 체크 해제 시 제외, 다른 기본 상품 선택 시 합계 재계산 확인.
- 상품선택 시 서랍 자동 오픈, ESC로 닫기, 모바일 전체 폭, 마지막 미팅 요약/JSON 상태 반영 확인.
- 각 슬라이드 데스크톱 및 모바일 가로 넘침 현상 없음. 모바일 슬라이드는 세로 스크롤이 필요합니다.

**배포:** 이 ZIP은 `index.html`을 루트에 둔 정적 사이트 구성으로, Netlify Drag & Drop 프리뷰 등에서 기술 확인할 수 있습니다. 운영 배포 또는 실제 채널 정보 수정은 수행하지 않았습니다.
